03 · Порядок як дані

integrator(options) отримує весь порядок.

Configurаtor не вирішує, який порядок “розумний”. Він перевіряє лише точний контракт: усі три steps, рівно один раз.

await runPipeline({ transactions, steps: [ "fraud-detector", "transaction-validator", "compliance-checker" ], sharedRoot, config }); // allowed
